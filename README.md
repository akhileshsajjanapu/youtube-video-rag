YouTube Video RAG
A Retrieval-Augmented Generation (RAG) system that extracts transcripts from YouTube videos, stores semantic chunks in ChromaDB, and generates precise, timestamp-aware answers using the Gemini API.

🚀 Features
YouTube Transcript Extraction: Automatically fetches and processes transcripts from any target YouTube video.

Semantic Retrieval: Breaks video content into meaningful semantic chunks for high-relevance search.

Vector Storage: Utilizes ChromaDB for efficient and scalable vector embedding storage.

Gemini-Powered Answers: Leverages state-of-the-art Google Gemini models to synthesize natural, accurate responses.

Timestamp-Aware Responses: Cites specific video timestamps so you can jump straight to the source material.

🛠️ Tech Stack
AI & LLM: Google Gemini API

Vector Database: ChromaDB

Orchestration & Framework: LangChain

Environment: Google Colab

Data Retrieval: YouTube Transcript API
