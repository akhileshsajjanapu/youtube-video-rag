#  YouTube Video RAG

A Retrieval-Augmented Generation (RAG) system that extracts YouTube transcripts, stores semantic chunks in ChromaDB, and answers questions using Gemini.

## Features
- YouTube transcript extraction
- Semantic retrieval
- ChromaDB vector storage
- Gemini-powered answers
- Timestamp-aware responses

## Tech Stack
- Gemini API
- ChromaDB
- LangChain
- Google Colab
- YouTube Transcript API
